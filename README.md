# Matters that Matter for Homebrew

The command line and MCP server of [Matters that Matter](https://matters-that-matter.app/), the Obsidian plugin for Matters and Actions.

```bash
brew install manueldelgado/tap/matters-that-matter
```

This installs the command `matters-that-matter` (and Node.js, which it needs). Then:

```bash
matters-that-matter today --vault ~/path/to/vault
```

Run `matters-that-matter --help` for every command, and see [the command line](https://matters-that-matter.app/docs/connect/command-line.html) and [AI assistants](https://matters-that-matter.app/docs/connect/ai-assistants.html) in the docs. The same package is on npm as `matters-that-matter`.
